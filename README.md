# One Word for the Boss

One word describing a boss: **Blamethrower**.

A blamethrower is a boss who sprays blame in every direction, like a
flamethrower, then walks through the smoke as if nothing happened. It is
funny on its own, it rings true for anyone who has reported to one, and it
works in any workplace — office, kitchen, or warehouse.

## How it works

`main.ts` (Node 22, standard library only) writes exactly that one word —
12 characters, no spaces, no trailing newline — to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR` when set, else `/output`).

## Run

```sh
node main.ts
```
